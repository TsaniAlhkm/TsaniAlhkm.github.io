Organizational project · Power BI

HPMI Financial Reporting Dashboard

Help organizational reviewers explore income, expenses and balances across reporting periods and units.

Data and approach

Organizational financial records are presented on separate Indonesian rupiah and Jordanian dinar pages. Date and reporting-unit filters work alongside summary cards, charts and transaction tables.

Analytical focus

The report separates currencies and lets reviewers move from summaries to activity-level records. It is designed to support questions about where funds were received or spent and how activity varies over time.

Output and limits

A working Power BI report file is available locally. Currency conversion rules, balance reconciliation and refresh behavior need further documentation before quantitative conclusions are published. No measured cost savings or reporting-time improvements are claimed.

Public demonstration pending an aggregate, shareable version of the organizational data.

Organizational project · Power BI

HPMI Student Distribution Dashboard

Support access to student information and exploration of university, study-field and arrival-cohort distributions.

Data and approach

The report combines organizational student records with tables, search filters and geographic views. The Amman Family version has Home, Maps and Info pages.

Analytical focus

Category views support questions about how student records are distributed across universities and study fields. Search and tabular views support internal information retrieval.

Output and limits

Power BI report files demonstrate implemented pages and filters. Population coverage, duplicate handling and geographic aggregation still need documented validation. The public case study excludes names and home locations.

Independent learning project · pandas · Plotly · Power BI

Global COVID-19 Time Series Analysis

Explore how reported observations change over time and across geographic areas.

Data and approach

The local source contains 289 rows, four metadata columns and 1,143 date columns. Python notebooks reshape the time series, calculate differences and build reporting summaries; a Power BI report provides another view of the data.

What needs validation

Cumulative observations must be distinguished from daily changes. Existing notebook variants contain different calculation paths, so a canonical run and reconciliation are required before publishing numerical findings. Negative revisions and date alignment also need explicit handling.

Supporting learning project · Python · IBM course

Stock and Revenue Data Extraction

Practice extracting and preparing historical stock and revenue data for comparison.

Approach

Retrieve share-price history with yfinance, extract revenue tables from course-provided webpages using BeautifulSoup, clean currency strings and empty values, then use the supplied Matplotlib plotting function.

Limits

This is an IBM course assignment. The graphing function is supplied in the course, and the project does not demonstrate a production data integration or an investment recommendation.

Independent project · SQL · Relational investigation

SQL Investigation Case Study

Completed seven fictional investigations in Database Detective: Minor Crimes Division by translating clues into SQL queries and progressively narrowing evidence.

Approach

Used filters, multi-table joins, SUM, AVG, MAX, COUNT, GROUP BY, HAVING, calculated fields and ORDER BY. Connected intermediate query results to later tables and revised join conditions, thresholds and calculations after inspecting results.

Evidence and limits

The game save and logs contain completion markers for Cases 1–7 and 101 distinct query strings. The game uses a custom parser, so the project demonstrates core relational reasoning rather than production database experience. CTEs, subqueries and window functions are not claimed.
